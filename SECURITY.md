# Security Policy

## Security Scope

The ETIS repository is the authoritative source for the ETIS Framework website, the *Engineering Trustworthy Intelligent Systems (ETIS)* Two-Volume Edition, the ETIS Publications Program, the Educational Ecosystem, the Platform gateway, appendices, downloads, and related public framework resources.

This repository is primarily a documentation, publication, and educational-resource repository. It does **not** provide hosted software services, production APIs, cloud infrastructure, or applications that process user data.

The companion **ETIS Engineering Platform Starter Kit** is maintained in a separate repository and follows its own security policy and reporting process.

---

## Supported Components

The following components are within the scope of this repository's security policy.

| Component | Supported |
|----------|-----------|
| ETIS Framework website | Yes |
| GitHub repository | Yes |
| GitHub Pages deployment | Yes |
| MkDocs configuration | Yes |
| Website build configuration | Yes |
| Publication assets | Yes |
| Downloads and public resources | Yes |
| Platform gateway | Yes |
| Documentation build pipeline | Yes |
| ETIS Engineering Platform Starter Kit repository | No (report through that repository) |

---

## Reporting Security Issues

If you believe you have discovered a security-related issue affecting:

- the ETIS Framework website;
- GitHub repository configuration;
- GitHub Pages deployment;
- MkDocs build or publication configuration;
- repository infrastructure;
- website assets;
- download infrastructure;
- GitHub Actions or deployment workflows (when applicable);
- dependency vulnerabilities associated with this repository;

please report the issue privately to the repository owner before making any public disclosure.

Responsible disclosure helps protect users while allowing appropriate investigation and remediation.

---

## Supported Versions

| Version | Supported |
|----------|-----------|
| 1.x | Yes |
| < 1.0 | No |

Only the current public release line receives security review.

---

## Responsible Disclosure

Please include, when possible:

- description of the issue;
- affected component(s);
- reproduction steps;
- potential impact;
- suggested remediation (if known);
- supporting screenshots, logs, or proof-of-concept information.

Reports will be reviewed and evaluated based on risk, reproducibility, and impact. Appropriate corrective action will be taken when warranted.

---

## Out of Scope

The following are **not** considered security vulnerabilities:

- typographical errors;
- documentation improvements;
- publication corrections;
- broken internal or external links;
- figure, formatting, or rendering issues;
- educational content corrections;
- framework discussions or doctrinal feedback;
- feature requests or enhancement proposals.

These should be reported through the normal publication or repository feedback process.

---

## Engineering Platform

Security issues affecting the **ETIS Engineering Platform Starter Kit** should be reported through the Starter Kit repository rather than this repository.

Framework documentation and Platform implementation are maintained as separate repositories with independent governance.
